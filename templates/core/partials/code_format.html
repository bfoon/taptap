The router checks small and capital letters exactly. Your customer portal currently turns every code into CAPITALS. Customers still log in while TapTap is reachable (TapTap knows the real code), but if your Internet line is down the router would refuse abcd typed as ABCD.
The token size counts every character, prefix and suffix included — exactly what the customer types. Letters-and-numbers codes skip look-alikes (0/O, 1/I); small letters skip l and o; mixed case uses only letters whose capital and small forms look different.
