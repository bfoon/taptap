How it works & tips for posters
1 · The router knows the nameEach router answers the name with its own hotspot address, so it only works on your Wi-Fi — no domain to buy.
2 · The login page forwardsThe TapTap login page sees which address was typed and sends the phone to the online sign-in, shop or page you chose.
3 · TapTap counts itEvery open is counted here. “Router login page” addresses open directly and still work when your Internet is down.
  • On posters write http://name or name/ (with the slash): some browsers treat a bare name like taptap.wifi as a search.
  • Avoid names ending in a number (taptap.1) — browsers refuse them — and .local, which iPhones never ask the router about.
  • Endings like .wifi, .hotspot or .login are not real internet endings, so they never clash with a real website.
  • Already logged-in customers see the router's status page (time left) instead.
