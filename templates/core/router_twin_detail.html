{% if twin.switch_over == 'ssid' %}
  1. Give the access points of both routers the same Wi-Fi name (and password, if any).
  2. Press Same login page on the standby above, so customers see the page they know.
  3. When {{ twin.primary.name }} goes quiet, phones join {{ twin.standby.name }} by themselves and log in with the code they have. Their time keeps counting from where it was.
{% elif twin.switch_over == 'vrrp' %}

Both routers on the same customer network. The main router answers on a shared gateway address; the standby takes it over within seconds when the main one stops (VRRP). Test it out of business hours — TikLab can simulate it first.

{% else %}

  3. Customers log in with the code they have — nothing to re-print.
